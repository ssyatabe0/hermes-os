# 06. 富裕層特有の需要調査

調査日: 2026-08-15
本ページは指示書セクション3・9・11・22の内容を整理したもの。定量調査（アンケート等）は
未実施のため、すべて `confidence=low〜medium` の仮説として扱い、実際の問い合わせ内容から
検証していく。

## 1. ターゲット顧客層

- 経営者・会社役員・高所得専門職（医師・士業等）
- 高所得共働き世帯
- 高級マンション・タワーマンション居住者
- 邸宅所有者、不動産所有者、賃貸物件オーナー、複数物件所有者
- セカンドハウス所有者
- 外国人居住者（特に富裕層）
- 不在期間が長い住宅所有者

## 2. 価格以外の価値訴求ポイント（仮説）

一般的なSEOキーワード（「安い」「格安」「相場」）とは別に、次のような**非価格軸の
検索意図・ニーズ**が存在すると仮定し、記事構成・LP設計で拾いに行く。

| ニーズ | 具体例 | コンテンツ・訴求への反映方針 |
|---|---|---|
| 業者を自分で探す手間を省きたい | 「信頼できる業者を紹介してほしい」 | 「業者選定代行」を前面に出したLP・記事 |
| 立ち会いたくない／自宅に知らない人を入れたくない不安 | 「鍵預かり対応」「不在時施工」 | 施工管理・報告写真つきのプロセスを明示 |
| 窓口を一本化したい | 「複数業者に連絡するのが面倒」 | 住宅設備一括管理・緊急時ワンストップ窓口の訴求 |
| 定期的な安心を買いたい | 「気づいたら壊れていた、を避けたい」 | 定期点検・定期清掃のサブスク提案 |
| セカンドハウス・複数物件の管理 | 「普段住んでいない家の管理」 | 留守宅・空き家管理、定期巡回・報告サービス |
| 管理組合・管理規約への対応 | 「タワマンの工事届出が面倒」 | 管理規約に沿った手続き代行を明記 |
| 外国人居住者の言語・商習慣ギャップ | 「日本語でのやり取りに不安がある」 | 英語対応可否の明示（体制構築は将来課題） |

## 3. 「高いから売れない」ではなく「高くても買われる理由」を探す

指示11の趣旨どおり、価格の高さそのものを弱点と捉えない。仮説として、富裕層セグメントは
以下の場合に高単価でも発注する:

1. 発注までの検索・比較・電話のやり取りに時間を使いたくない（時間コストの方が高い）
2. 過去に業者トラブル（雑な工事、connectionが切れた、金額を後出しされた等）を経験している
3. 資産価値の維持（邸宅・マンションの資産性）に直結する工事だと認識している
4. 管理会社や知人からの紹介がなく、検索で信頼できそうな窓口を探している

→ コンテンツでは「価格の安さ」ではなく「対応の速さ」「施工管理の透明性（写真報告等）」
「窓口の一本化」「実際の作業範囲・工程の明確さ」を訴求軸にする。ここでいう「工程の明確さ」は
架空の施工実績や口コミではなく、**一般的な作業内容・工期の説明**として提供する
（指示28・52の禁止事項に抵触しないよう、実績を捏造しない）。

  （このデータ自体が「富裕層ニーズの実測値」という独自資産になる）
