# 01. 東京8区 地域分析

調査日: 2026-08-15
調査方法: WebSearch（各区公式統計ページ、e-Stat、東京都統計、住宅系メディア記事）
凡例: **[実測]** = 一次情報源で確認した数値 / **[推定・一般知識]** = 学習済み一般知識ベースで
未検証（今回のセッションでは個別検索していない） / **[取得不能]** = このセッションでは
数値へ到達できず、次回取得のための出典ページのみ特定済み

> 重要: このドキュメントの数値は `db/hermes.db` の `region_metrics` テーブルに
> `data_type` / `confidence` / `source_url` / `collected_at` を付けて格納している。
> ダッシュボードやスコアリングで参照する際は必ずDB側の `data_type` を見ること。

## 0. 8区サマリ（優先度）

| 区 | 優先度 | 特徴（要点） |
|---|---|---|
| 港区 | 最優先 | 23区で世帯当たり所得トップ級。麻布・白金・高輪・赤坂に富裕層集積。タワマン・大使館・法人多数 |
| 品川区 | 最優先 | 都心近接＋湾岸再開発（天王洲・大崎）。御殿山・島津山・池田山に古くからの邸宅街。東五反田は高級マンション激戦区 |

| 大田区 | 重点 | 田園調布が最上位ブランド住宅地。区全体では戸建て比率が高く面積も広いため町丁目差が大きい |
| 千代田区 | 重点 | 23区最小人口・最高所得層の一つ。番町・麹町が最上位邸宅街。夜間人口少なく法人需要中心 |

| 新宿区 | 重点 | 下落合・若葉・信濃町周辺に邸宅街があるが区全体は単身・賃貸比率が高く二極化 |
| 目黒区 | 重点 | 自由が丘・八雲・青葉台・碑文谷が高級住宅地。中目黒はブランドイメージ先行 |

### 1.2 富裕層・住宅特性（町丁目レベル）
以下は不動産・住宅系メディアで繰り返し言及される「高級住宅街」認識であり、公的統計ではないため
`confidence=medium` として扱う。

| エリア | 特徴タグ |
|---|---|
| 麻布・元麻布・南麻布 | 大使館多数、邸宅・高級マンション混在、外国人居住多い |
| 西麻布・六本木 | 高級マンション、商業施設近接、法人利用も多い |
| 白金・白金台 | 邸宅街、閑静、教育環境良好、富裕層の定番エリア |
| 高輪 | 邸宅・高級マンション、再開発（高輪ゲートウェイ）で価値上昇傾向 |
| 赤坂 | 高級マンション、法人・政治関連施設近接 |
| 三田 | 大学（慶應）近接、マンション・邸宅混在 |
| 芝浦・港南 | タワーマンション集積（湾岸）、比較的築浅、共働き・ファミリー層 |

出典: [東京の高級住宅街(アーネストアーキテクツ)](https://earnest-arch.jp/column/luxury-residential-area/tokyokokyu/) 他複数メディア（confidence=medium）

### 1.3 サービス需要仮説
- タワーマンション（芝浦・港南）: エアコンクリーニング、水回り、宅配ボックス絡みの小修繕、
  管理組合ルール対応が必要な作業（工事届出等）
- 邸宅街（麻布・白金・高輪）: 庭木剪定、外壁・屋根、リフォーム、不在時対応・鍵預かり需要
- 大使館・外国人居住エリア: 英語対応可能な窓口への潜在ニーズ（要検証）

## 3. 渋谷区・大田区・千代田区・世田谷区・新宿区・目黒区（重点6区）

このセッションでは港区・品川区を優先し、他6区は町丁目レベルの高級エリア特定を中心に実施。
区別の人口・世帯・持ち家率は次回セッションで各区公式統計ページから実測取得する
（`TODO.md` P4に記載）。

| 区 | 主要高級・戸建てエリア（confidence=medium、複数メディア一致分のみ） | サービス仮説 |
|---|---|---|
| 渋谷区 | 松濤、広尾、代官山、恵比寿西 | 邸宅の庭・外構、外国人居住者向け窓口ニーズ、高級マンションの水回り・清掃 |
| 大田区 | 田園調布、雪谷、久が原、山王 | 戸建て比率が高く庭・外構・剪定の需要面積が広い。田園調布はブランド邸宅街の最上位格 |
| 千代田区 | 番町、麹町 | 世帯数自体は少ないが超高所得層。法人（オフィスビル）需要のBtoB比率が他区より高いと推定 |
| 世田谷区 | 成城、岡本、深沢、奥沢、玉川田園調布 | 23区最大人口・戸建て比率高い。庭・外構・剪定・草刈りの絶対量が期待できる最重点候補 |
| 新宿区 | 下落合、若葉、信濃町周辺 | 区全体は単身・賃貸中心で二極化。エリアを絞った訴求が必要 |
| 目黒区 | 自由が丘、八雲、青葉台、碑文谷、中目黒 | 高級住宅とブランド商業エリアが近接。ハウスクリーニング・庭木剪定と相性良さそう |

出典: [目黒区の高級住宅街(アーネストアーキテクツ)](https://earnest-arch.jp/column/luxury-residential-area/meguro/),
[東京の高級住宅街完全ガイド](https://selectmodernluxury.com/tokyo-luxury-residential-area/) 他

### 補足（一般知識ベース、未検証 — confidence=low、次回検証必須）
以下は区の規模感についての一般的に知られた序列であり、本セッションで個別に数値検証していない。
スコアリングの参考程度に留め、実測値取得後に置き換える。

- 世田谷区は23区中で人口最多クラス、千代田区は最少クラス（昼夜間人口差が大きい）
- 大田区・世田谷区は区面積が広く、戸建て住宅の絶対ストックが多い
- 千代田区・港区は事業所（法人）密度が23区でも突出して高い

## 4. 取得不能データと代替方法まとめ

| データ | 状態 | 代替方法 |
|---|---|---|
| 8区の正確な人口・世帯数（港区含む6区） | 取得不能（品川区のみ実測済） | 次回、各区公式統計ページ／e-Statから直接転記 |
