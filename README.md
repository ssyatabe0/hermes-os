# hermes-os

東京都8区（港区・品川区を最優先、渋谷区・大田区・千代田区・世田谷区・新宿区・目黒区を重点）を
初期商圏とする、地域×住宅サービスのデータ蓄積プロジェクト。

単なるアフィリエイト/リフォームサイトではなく、「地域×困りごと×サービス×顧客属性×季節×
収益性」を実測データとして蓄積し、利益性の高いサービスから自社受付化していく
「集客主導型の地域サービス会社」を目指す。

作業を始める前に **[`AGENTS.md`](./AGENTS.md)** を読むこと。続けて `STATUS.md` → `TODO.md` →
`DECISIONS.md` の順に読めば、これまでの経緯を読み返さなくても作業を再開できる。
